# TradeWay CRM — справка для работы

## Что это
- CRM компании TradeWay: международное экспедирование (Европа и Украина, алкоголь и косметика).
- Весь сайт находится в одном файле `index.html`. Он публикуется через GitHub Pages из этого репозитория.
- Владелец не программист. Объясняй простыми словами, без технических терминов.

## Данные
- База данных: Supabase (регион Стокгольм). Таблицы: `clients` (клиенты), `carriers` (перевозчики), `trips` (рейсы), `documents` (документы).
- Сами файлы документов лежат в Google Drive. В базе хранятся только ссылки на них.
- Вход только по логину и паролю. Регистрация новых пользователей выключена.

## Деньги
- Чистая прибыль = доход − расход − налог, всё в евро.
- Налог берётся из поля `tax_eur` (доход: `income_eur`, расход: `cost_eur`).

## Правила безопасности
- Секретные ключи (`sb_secret`, `service_role`) и пароли никогда не писать в файлы и не показывать в ответах.
- В коде допустим только публичный ключ `sb_publishable_`.
- Не создавать пользователей и не менять данные в рабочей базе без явной просьбы владельца.

## Как работаем
- Перед изменениями проверять код на ошибки синтаксиса. Node на компьютере не установлен, поэтому проверяем встроенным в macOS движком JavaScript (`osascript -l JavaScript`).
- После изменений делать коммит с понятным описанием.
- Отправка на GitHub сейчас делается вручную, кнопкой «Push origin» в GitHub Desktop.
- Ничего не удалять без подтверждения.

## Известные особенности
- Рейсы перенесены из Google таблицы. Все исходные колонки сохранены в поле `legacy` (тип jsonb) у каждого рейса. На странице рейса их можно раскрыть в блоке «Исходные данные из старой таблицы».
